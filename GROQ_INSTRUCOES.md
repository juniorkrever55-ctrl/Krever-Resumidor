GROQ — PASSO A PASSO
1. Acesse console.groq.com
2. Cadastre-se (email/Google)
3. Vá em API Keys -> Create Key -> copie
4. Cole no código como GROQ_API_KEY=...
5. Limite: nível gratuito tem rate limit (não é infinito)
TROCAR PARA LOCAL DEPOIS: troque a URL do fetch de api.groq.com para http://localhost:11434 e instale Ollama.
